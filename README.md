# pregap.app

The website for [Pregap](https://pregap.app), the audio CD burner for the Mac:
the home page, [help](https://pregap.app/help.html) and the
[privacy policy](https://pregap.app/privacy.html).

This repo holds only the published files, served by GitHub Pages at
**pregap.app**. It is generated from the app's own (private) repository, so
changes made here directly would be overwritten by the next publish. Each commit
names the source commit it was published from.

Questions or problems: [support@pregap.app](mailto:support@pregap.app)
